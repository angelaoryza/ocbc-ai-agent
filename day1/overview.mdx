This masterclass teaches you to build an end-to-end AI agent system, using AI-assisted coding. Today is Day 1: across seven sessions you build the data, automation, AI-call and retrieval layers of a finance assistant for Harapan Mitra Niaga, a fictional company, by talking to an AI coding agent. The first half teaches what an AI is and builds the data layer. The second half automates a daily report, gives the app its own AI call and finishes with a chatbot that answers from the news and shows its sources.

| Session | What you do |
|----|----|
| [0 Opening](/day1/s0) | Meet OpenCode; see why a vague prompt fails |
| [1 What is an AI?](/day1/s1) | Model, thinking effort, tokens, guardrails |
| [2 Building with an AI teammate](/day1/s2) | Plan, implement, test, repeat; skills |
| [3 The data layer](/day1/s3) | API, web page and CSV data on a four-tab app |
| [4 Automation](/day1/s4) | A scheduled daily report on the Reports tab |
| [5 The first AI call](/day1/s5) | A grounded, safe, structured AI morning digest |
| [6 AI Wiki, RAG and the chatbot](/day1/s6) | The Assistant tab, answering with sources |

How to read this book. Every session has a ▶ Do it step (a prompt to send) and a What to look for check. Nothing here is investment advice: the stock data is for practice only.
