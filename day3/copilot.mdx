## Prompts to try in Copilot

- "In App.jsx, add a button that clears the conversation."
- "Show each answer's tools as small coloured tags instead of plain text."
- "Add a sidebar listing BBCA, BBRI, BMRI and NISP; clicking one asks for its overview."
- "In backend/agent.py add a tool that returns the dividend yield of a bank, and update the system prompt."
- "Change the colours to match our brand and make the page work on a phone."

See [Read the code](/day3/read-the-code) for which file each prompt changes.

## When something breaks

Read the red text in the terminal (backend) or the browser console, **F12** (interface), and paste it into Copilot.

For the common errors, see [Where things go wrong](/day3/setup-and-run#where-things-go-wrong).
