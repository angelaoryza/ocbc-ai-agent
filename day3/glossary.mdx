| Term | Meaning |
|----|----|
| API | A set of addresses a program can call to get data or do work |
| Backend | The Python side of the system. It holds the agent and the doorway the page calls |
| Build | Producing the plain HTML, JavaScript, and CSS files of the page |
| Component | A piece of the page with its own logic and appearance |
| CORS | The browser rule that blocks a page from calling a different address without the server's permission |
| Doorway | The small Python file, `main.py`, that lets the page send questions to the agent |
| Endpoint | One address in an API, such as `/api/chat` |
| FastAPI | The Python library that connects addresses to functions |
| GET and POST | Request types. GET fetches, POST sends data |
| HTTP | The language browsers and servers use to send requests and responses |
| JSON | A text format for structured data, written like a Python dict |
| JSX | HTML-like syntax inside JavaScript |
| localhost | The name for your own computer |
| Log | A text file where a program writes what it did |
| npm | The JavaScript package installer, like pip |
| Port | A numbered entrance on a computer. The backend uses 8000 and the page uses 5173 |
| Proxy | A program that forwards requests from one address to another |
| React | The JavaScript library that draws the page from data |
| State | A variable React watches and redraws the page on |
| Status code | A number in the response<br />• 200 means success<br />• 400 means a bad request<br />• 500 means a server error |
| uvicorn | The program that listens on a port and passes requests to FastAPI |
| Vite | The tool that serves the page while you develop and builds the final files |
