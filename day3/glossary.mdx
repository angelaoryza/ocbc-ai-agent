| Term | Meaning (section where introduced) |
|----|----|
| **API** | A set of addresses a program can call to get data or do work (1.3) |
| **Back end** | The Python side: the agent, the tools and the routes the page calls (1.3) |
| **Build (npm run build)** | Producing the plain HTML, JavaScript and CSS files of the page, in `dist/` (A.2) |
| **Component** | A piece of the page with its own logic and look (0.2, 2.1) |
| **CORS** | The browser rule that blocks a page from calling another address without permission (1.3) |
| **Doorway** | The address /api through which the page reaches the back end (1.3) |
| **Endpoint** | One address in an API, such as /api/chat; the same as a route (1.3) |
| **Error state** | What a component shows when the back end fails (2.1) |
| **FastAPI** | The Python library that connects addresses to functions (1.3) |
| **Front end** | What the user sees and clicks; in the capstone, a React page (1.2) |
| **GET and POST** | Request types: GET fetches, POST sends data (1.4) |
| **HTTP** | The language browsers and servers use to send requests and answers (1.2) |
| **Interface** | The place where people meet the system (1.1) |
| **JSON** | A tidy text format for structured data (1.2) |
| **JSX** | HTML-like layout written inside JavaScript (2.1) |
| **Key (in a list)** | An id that does not change, so React updates the right item (2.1) |
| **localhost** | The name for your own computer (1.3) |
| **Loading state** | What a component shows while it waits for the back end (2.1) |
| **Log** | A text file where a program writes what it did (1.4) |
| **Node.js** | Runs JavaScript outside the browser (0.3) |
| **npm** | The JavaScript package installer, like pip (0.3) |
| **Port** | A numbered entrance on a computer: 8000 for the back end, 5173 for the page (1.3) |
| **Props** | Read-only data a parent hands to a child component (2.1) |
| **Proxy (forwarding)** | A program that forwards requests from one address to another (1.3) |
| **React** | The library that draws the page from components and redraws when data changes (0.2) |
| **Route** | One address in an API, connected to one function (1.3) |
| **State** | A value React watches; when it changes, the page redraws (2.1) |
| **Status code** | A number that says how a request went: 200, 400, 422, 500, 502 (1.3) |
| **systematic-debugging** | The skill that finds the cause of a failure before it changes anything (6.1) |
| **uvicorn** | The program that listens on a port and passes requests to FastAPI (1.3) |
| **Vite** | The tool that serves the page while you work and builds the final files (1.3, A.1) |
