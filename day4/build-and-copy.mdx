Run these on your laptop in PowerShell.

<Steps>
  <Step title="Build the page">
    This writes `dist/`, which holds plain HTML, JavaScript, and CSS. The server needs no Node.

    ```powershell
    cd <course-folder>\day3\starter\frontend
    npm run build
    ```
  </Step>
  <Step title="Create the folder on the server">
    ```powershell
    ssh root@<server-ip> "mkdir -p /opt/idx-assistant"
    ```
  </Step>
  <Step title="Copy the files">
    Each `scp` command asks for the password.

    ```powershell
    cd <course-folder>
    scp -r day3\starter\backend root@<server-ip>:/opt/idx-assistant/
    scp -r day3\starter\frontend\dist root@<server-ip>:/opt/idx-assistant/
    scp day4\deploy\requirements-server.txt root@<server-ip>:/opt/idx-assistant/
    scp .env root@<server-ip>:/opt/idx-assistant/.env
    ```
  </Step>
</Steps>

`node_modules` stays on your laptop because the server never runs Node.

<Warning>
The last command copies your keys. The `.env` file travels over the encrypted connection and never goes into git.
</Warning>
