Over four days the IDX Market Assistant grew one layer at a time.

| Layer | Day | What you built |
|----|----|----|
| Data | Day 1 | Tools that fetch Indonesian bank data from Sectors |
| Automation | Days 1 and 2 | Scripts that run the data steps on their own |
| Agent | Day 2 | An agent that picks the right tool for each question |
| Interface | Day 3 | A React page and a FastAPI doorway in front of the agent |
| Testing and logging | Day 4 | • A test sheet<br />• Quality checks<br />• A log of usage, latency, and errors |
| Hosting | Day 4 | A server with nginx and systemd that keeps the system running for others |
| Sharing | Day 4 | A short walkthrough of the use case and the prototype for peers |

The same pattern fits any idea. It has five steps.

1. Put the data behind tools.
2. Give the tools to an agent.
3. Put a page in front of the agent.
4. Test it and watch its log.
5. Run the whole thing on a server that stays on.
