This guide moves the app from your laptop to a server. The sections follow the five items of Module 10.

## What the guide assumes

- The server runs Ubuntu 22.04 or newer, or Debian 12 or newer, and installs software with `apt`.
- You log in with `ssh root@<server-ip>` and a password.
- The server reaches the internet for `apt` and `pip`.
- The app is built and working on your laptop, with a `.env` file in the course folder.

Replace `<server-ip>` in every command with the address of your server, and `<course-folder>` with the path of the course folder on your laptop.

## What runs where

| Piece | On your laptop | On the server |
|---|---|---|
| Page | Vite dev server on port 5173 | Built files in `/opt/idx-assistant/dist`, served by nginx on port 80 |
| Backend | uvicorn, started by hand on port 8000 | uvicorn, run by systemd on port 8000 |
| Forwarding `/api` | Vite proxy | nginx |
| Keys | `.env` in the course folder | `.env` in `/opt/idx-assistant` |
| Logs | The terminal and `logs/app.log` | `journalctl` and `/opt/idx-assistant/logs/app.log` |

The folder on the server looks like this.

```text
/opt/idx-assistant/
    backend/                 main.py, agent.py
    dist/                    the built page
    logs/                    app.log, written by the backend
    .venv/                   Python packages
    .env                     the keys
    requirements-server.txt  package list
```

## Reading the commands

Most command names are shortened phrases. Once you know the long form, the name explains itself.

| Command | Long form | What it does |
|---|---|---|
| `ssh` | Secure Shell | Opens an encrypted command line on another computer. In `ssh root@<server-ip>`, `root` is the account and `@` reads as "at". |
| `scp` | Secure Copy | Works like `cp`, the copy command, over SSH. The `-r` flag means recursive, so it copies a folder and everything inside it. |
| `cat` | Concatenate | Prints a file on the screen. |
| `cd` | Change directory | Moves into a folder. |
| `mkdir -p` | Make directory | Creates a folder. `-p` also creates missing parent folders and gives no error when the folder exists. |
| `apt` | Advanced Package Tool | Installs software on Ubuntu and Debian. |
| `venv` | Virtual environment | A private folder of Python packages for one project. |
| `pip` | Pip Installs Packages | Installs Python packages. |
| `chown -R` | Change owner | Gives a file or folder to a user. `-R` applies it to everything inside. |
| `chmod 600` | Change mode | Sets who can read and write a file. `600` means the owner reads and writes and nobody else does. |
| `sudo -u` | Superuser do | Runs a command as another user. `-u` names the user. |
| `curl` | Client URL | Sends a request to an address and prints the answer. |
| `systemctl` | System control | Talks to systemd, the system daemon. A daemon is a program that runs in the background. |
| `pkill -f` | Process kill | Stops a program by name. `-f` matches the full command line. |
| `ln -s` | Link, symbolic | Creates a shortcut to a file. |
| `rm -f` | Remove | Deletes a file. `-f` forces it and gives no error when the file is missing. |
| `nginx -t` | Test | Checks the configuration file. The name nginx is pronounced "engine x". |
| `ufw` | Uncomplicated Firewall | Controls which ports accept traffic. |
| `tail -n 20` | Tail, number of lines | Prints the last 20 lines of a file. `-f` follows the file and prints new lines as they arrive. |
| `journalctl -u` | Journal control, unit | Reads the systemd journal for one service, called a unit. |
