| Term | Meaning |
|----|----|
| A record | A DNS record that connects a name to an IP address |
| DNS | Domain Name System, the phone book that turns a name into an IP address |
| Domain | A name that points to an IP address, such as `assistant.example.com` |
| Environment file | The `.env` file that holds the keys and the settings of a machine |
| grep | Global regular expression print, a command that prints the lines matching a pattern |
| Hosting | Running a program on a computer that other people can reach over a network |
| Instrumenting | Adding code that records what a system does |
| IP address | The number that identifies a computer on a network |
| journalctl | Journal control, the command that reads the systemd journal |
| Latency | How long a request takes, measured in milliseconds |
| localhost | The name for your own computer |
| Log | A text file where a program writes what it did |
| Log level | How serious a log message is, such as INFO or ERROR |
| Log rotation | Starting a new log file when the current one reaches a size limit, and keeping a few old ones |
| Managed process | A program that a process manager keeps running |
| Middleware | A function that runs around every request, before and after the route |
| Monitoring | Reading the log on a regular schedule |
| nginx | Pronounced "engine x", the web server that serves the page and forwards `/api` to the backend |
| Port | A numbered entrance on a computer |
| Quality check | A check that an answer is right, for example by comparing its numbers with the tool results |
| Reverse proxy | A program at the entrance of a server that forwards each request to the right program |
| root | The administrator account of a Linux server |
| Sample input | An input the system was built for |
| scp | Secure Copy, the command that copies files over SSH |
| Server | A computer that waits for requests and answers them |
| SSH | Secure Shell, an encrypted command line on another computer |
| systemctl | System control, the command that controls systemd services |
| systemd | System daemon, the process manager built into most Linux servers |
| tail | A command that prints the end of a file, the last lines |
| Test sheet | A table with one row per test |
| Unexpected input | An input a real user sends that the builder did not plan for |
| VPS | Virtual private server, a computer in a data center that you control from another machine |
