---

| Term | Meaning (section where introduced) |
|----|----|
| **A record** | A DNS record that connects a name to an IP address (4.5) |
| **DNS** | Domain Name System, the phone book that turns a name into an IP address (4.5) |
| **Domain** | A name that points to an IP address, such as assistant.example.com (4.5) |
| **Environment file** | The `.env` file that holds the keys and settings of one machine (4.2) |
| **grep** | Global regular expression print, a command that prints the lines matching a pattern (A.2) |
| **Hosting** | Running a program on a computer that other people can reach over a network (3.2) |
| **Instrumenting** | Adding code that records what a system does (2.1) |
| **IP address** | The number that identifies a computer on a network (4.4) |
| **journalctl** | Journal control, the command that reads the systemd journal (4.6) |
| **Latency** | How long a request takes, measured in milliseconds (2.1) |
| **localhost** | The name for your own computer (3.1) |
| **Log** | A text file where a program writes what it did (2.1) |
| **Log level** | How serious a log message is, such as INFO or ERROR (2.1) |
| **Log rotation** | Starting a new log file at a size limit and keeping a few old ones (2.1) |
| **Managed process** | A program that a process manager keeps running (4.3) |
| **Middleware** | A function that runs around every request, before and after the route (2.1) |
| **Monitoring** | Reading the log on a regular schedule (2.2) |
| **nginx** | The web server that serves the page and forwards /api to the back end (4.4) |
| **Port** | A numbered entrance on a computer: 80 for nginx, 8000 for the back end (4.4) |
| **Quality check** | A check that an answer is right, for example by comparing its numbers with the tool results (1.4) |
| **Reverse proxy** | A program at the entrance of a server that sends each request to the right program (4.4) |
| **root** | The administrator account of a Linux server (4.1) |
| **Sample input** | An input the system was built for (1.2) |
| **scp** | Secure Copy, the command that copies files over SSH (4.1) |
| **Server** | A computer that waits for requests and answers them (3.2) |
| **SSH** | Secure Shell, an encrypted command line on another computer (4.1) |
| **systemctl** | System control, the command that controls systemd services (4.3) |
| **systemd** | System daemon, the process manager built into most Linux servers (4.3) |
| **Test sheet** | A table with one row per test: input, expected result, result, fix needed (1.2) |
| **Unexpected input** | An input a real user sends that the builder did not plan for (1.2) |
| **VPS** | Virtual private server, a computer in a data centre that you control from another machine (3.3) |
