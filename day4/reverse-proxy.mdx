A reverse proxy is the program at the public entrance. nginx serves the files of the page and forwards every request that starts with `/api` to the backend. Vite's proxy did this job on your laptop.

<Steps>
  <Step title="Copy the configuration from your laptop">
    ```powershell
    cd <course-folder>
    scp day4\deploy\nginx-idx-assistant.conf root@<server-ip>:/etc/nginx/sites-available/idx-assistant
    ```
  </Step>
  <Step title="Turn it on, on the server">
    ```bash
    ln -s /etc/nginx/sites-available/idx-assistant /etc/nginx/sites-enabled/idx-assistant
    rm -f /etc/nginx/sites-enabled/default
    nginx -t
    systemctl reload nginx
    ```

    `nginx -t` checks the file and prints `syntax is ok`.
  </Step>
  <Step title="Open port 80 in the firewall">
    Run `ufw status` on the server. When it reports `active`, run `ufw allow 80/tcp`.

    <Warning>
    This changes the server's firewall. Open port 80 only; the backend on port 8000 stays private behind nginx.
    </Warning>
  </Step>
  <Step title="Open the page">
    Open `http://<server-ip>` in your browser. The chat page appears. Click an example question.
  </Step>
</Steps>

## The nginx configuration

```nginx day4/deploy/nginx-idx-assistant.conf
server {
    listen 80;
    server_name _;

    # The built React page
    root /opt/idx-assistant/dist;
    index index.html;

    # Requests for /api go to the Python backend
    location /api/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_read_timeout 120s;
    }

    # Everything else is a file of the page
    location / {
        try_files $uri /index.html;
    }
}
```

| Part of `nginx-idx-assistant.conf` | What it does |
|---|---|
| `listen 80` | Accepts normal web traffic. |
| `root /opt/idx-assistant/dist` | The folder of page files. |
| `location /api/` with `proxy_pass` | Forwards `/api/...` to the backend on port 8000. |
| `proxy_read_timeout 120s` | Waits up to 2 minutes for the agent. The default is 60 seconds. |
| `location /` with `try_files` | Serves the page for every other address. |
