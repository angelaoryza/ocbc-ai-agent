The running example uses public market data from **Sectors** (`https://api.sectors.app/v2`) about four Indonesian banks: BBCA, BBRI, BMRI and NISP. So that everyone gets the same numbers, the notebooks use prices for one fixed month: **24 September to 23 October 2026**.

`data/sample/` holds saved copies of real Sectors responses from 25 October 2026, for when the API cannot be reached.

| File | What it is | Used in |
|---|---|---|
| `report_<TICKER>.json` | The company report of each bank | Module 2 example (fallback), Module 4 notebook |
| `daily_<TICKER>.json` | Daily prices of each bank | Module 2 notebook, example and exercise (fallback), Module 4 notebook |
| `news_<TICKER>.json` | The latest news about each bank, 20 articles per bank | Module 2 example (fallback), Module 5, 6 and 8 notebooks |
| `list_of_banks_in_indonesia.html` | The Wikipedia page *List of banks in Indonesia* | Module 2 notebook, section 2.4 |
| `top_banks_market_cap.json` | A ranking of banks by market cap | Reference copy |
| `top_movers_banks.json` | The banks that rose and fell most | Reference copy |
| `mcp_tools.json` | The tool list of the Sectors MCP server | Reference copy |
