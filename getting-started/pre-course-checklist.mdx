---

- [ ] The starter kit is on your laptop, from [Google Drive](https://bit.ly/OCBCTrainingDrive) or [GitHub](https://github.com/angelaoryza/starter-kit)
- [ ] OpenCode is installed and opens in the starter folder
- [ ] A model is connected and answers in the OpenCode chat
- [ ] Git is installed (OpenCode needs it to download Superpowers)
- [ ] Python 3.10 or newer is installed
- [ ] You have your Sectors key, and the AI key, address and model name from your trainer
- [ ] On an office network: the proxy settings from IT, in case `npm install` is blocked on Day 3
- [ ] Before Day 1, Session 2.7: Superpowers is added to OpenCode ([Day 1, Appendix A](/day1/appendix-a))
- [ ] Before Day 3, Session 0.3: Node.js and npm are installed. Let OpenCode check them for you ([Day 3, Appendix A](/day3/appendix-a))

See [Setup](/getting-started/setup) for each item.
