You do not write code in this course, so setup is short: an AI coding agent, a project folder, a few keys, and two tools that are used from Day 3.

## Get the training files

The training files are the starter kit: the project you open in OpenCode on Day 1, with the data it needs. Get them from either place:

- Google Drive: [bit.ly/OCBCTrainingDrive](https://bit.ly/OCBCTrainingDrive)
- GitHub: [angelaoryza/starter-kit](https://github.com/angelaoryza/starter-kit)

## What you need

| Tool | What it is for | When you need it |
|----|----|----|
| **OpenCode** | The AI coding agent you talk to all day. A model must be connected and answer in the chat. | Day 1, Session 0 |
| **The starter kit folder** | The project you work in. It is a Git repository, which is why undo works. | Day 1, Session 0 |
| **Git** | Lets OpenCode download the Superpowers plugin from GitHub. | Before Day 1, Session 2.7 |
| **Python 3.10 or newer** | Runs the back end. | From Day 1 |
| **Node.js and npm** | Run JavaScript outside the browser, and install the page's packages. Vite comes with the project. | Day 3 |
| **Your server login** | Details of your own server, from your trainer. | Day 4 |

## Add the skills

In Session 2 you use skills by name. [Day 1, Appendix A](/day1/appendix-a) shows how to add Superpowers to OpenCode. Do it once, before Session 2.7.

## Add your keys to `.env`

The app reads its keys from a private file called `.env`. Put each key on its own line, with no quotes, no spaces around `=` and no word Bearer. After you change a key, stop the back end with `ctrl+c` and start it again.

| Variable | What it is | First used |
|----|----|----|
| `SECTORS_API_KEY` | Your Sectors key ([sectors.app/api](https://sectors.app/api)) | Day 1, Session 3 |
| `OPENAI_API_KEY` | The AI key your trainer gives you | Day 1, Session 5 |
| `OPENAI_URL` | The AI address your trainer gives you | Day 1, Session 5 |
| `OPENAI_MODEL` | The AI model name your trainer gives you | Day 1, Session 5 |
| `SECTORS_MCP_URL` | The Sectors MCP server address | Day 2, Session 0 |

<Warning>
Never paste a key into the chat. Keys live in `.env` only, and the browser must never load them.
</Warning>
