Over the course you build the **IDX Market Assistant** on Indonesian stock data from [Sectors](https://sectors.app): a data script, a scheduled report, an LLM digest, RAG over news, tools, an agent with approval, MCP tools, and a scheduled agent that explains big price moves.

> Day 1: we tell the LLM what the data is. Day 2: the LLM asks for the data it needs.

Before the first session, work through [Setup](/getting-started/setup) and the [Pre-course checklist](/getting-started/pre-course-checklist).
