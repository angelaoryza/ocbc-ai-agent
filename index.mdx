In this course you learn agentic AI by building an end-to-end AI-based system: a data layer, automation, LLM calls, RAG, tools, an agent with approval, MCP, a web interface, and deployment to a server.

The use case is the **IDX Market Assistant**, which answers questions about Indonesian stocks with data from [Sectors](https://sectors.app). It gives every module something real to build on. The same steps apply to your own data and your own use case.

> Day 1: we tell the LLM what the data is. Day 2: the LLM asks for the data it needs.

Before the first session, work through [Setup](/getting-started/setup) and the [Pre-course checklist](/getting-started/pre-course-checklist).
