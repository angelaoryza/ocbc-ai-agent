This masterclass teaches you to build an end-to-end AI agent system, using AI-assisted coding. Over four days you build a finance assistant for **Harapan Mitra Niaga**, a fictional company, by talking to an AI coding agent, **OpenCode**. You never write code by hand. You describe, the AI builds, you check.

The stock data comes from [Sectors](https://sectors.app) and is for practice only. Nothing in this course is investment advice.

Every session has a ▶ **Do it** step (a prompt to send) and a **What to look for** check.

The training files are on [Google Drive](https://bit.ly/OCBCTrainingDrive) and on GitHub: [angelaoryza/starter-kit](https://github.com/angelaoryza/starter-kit).

Before the first session, work through [Setup](/getting-started/setup) and the [Pre-course checklist](/getting-started/pre-course-checklist).
